## **AI and Ethics Journal - Submission Guidelines**

### **Journal Overview**

* **Publisher** : Springer Nature
* **ISSN** : 2730-5953
* **Scope** : Ethical, regulatory, and policy implications of AI development
* **Peer Review** : Double-blind
* **Submission** : Rolling (no deadline)
* **Open Access** : Available (with APC)

---

### **1. MANUSCRIPT FORMAT**

**File Format**

* Word (.docx or .doc) OR LaTeX
* For LaTeX: Use Springer Nature's LaTeX template (`sn-basic.bst` for bibliography)

**Length**

* No strict word limit specified
* Based on published papers in the journal: typically **8,000–15,000 words** (including references)
* One special issue indicated minimum 10,000 words

**Structure**

* Maximum **3 levels of headings**
* Use automatic page numbering
* Use tab stops for indents (not space bar)
* Use table function for tables (not spreadsheets)
* Use equation editor or MathType for equations

**Abstract**

* **150–250 words**
* No undefined abbreviations
* No unspecified references

---

### **2. DOUBLE-BLIND REQUIREMENTS** ⚠️

**Anonymized Manuscript** (separate from title page):

* Remove all author names, affiliations, identifying information
* Remove acknowledgements from main manuscript
* Avoid self-citations that reveal identity (use third person: "Prior work showed..." not "Our prior work showed...")
* Anonymize supplementary files (figures, data)

**Separate Title Page** (submitted as separate file):

* Title
* All author names and affiliations
* Corresponding author contact information
* Acknowledgements
* Funding information
* All declarations

---

### **3. REFERENCE STYLE**

 **Format** : Springer Basic (Numbered, brackets)

 **In-text citations** :

* Single: `[1]`
* Multiple: `[1-3, 7]`

 **Bibliography examples** :

```
1. Hamburger, C.: Quasimonotonicity, regularity and duality for nonlinear 
   systems of partial differential equations. Ann. Mat. Pura Appl. 169, 
   321–354 (1995)

2. Sajti, C.L., Georgio, S., Khodorkovsky, V., Marine, W.: New nanohybrid 
   materials for biophotonics. Appl. Phys. A (2007). 
   https://doi.org/10.1007/s00339-007-4137-z

3. Geddes, K.O., Czapor, S.R., Labahn, G.: Algorithms for Computer 
   Algebra. Kluwer, Boston (1992)

4. Broy, M.: Software engineering — from auxiliary to key technologies. 
   In: Broy, M., Denert, E. (eds.) Software Pioneers, pp. 10–13. 
   Springer, Heidelberg (2002)
```

 **Key formatting rules** :

* Author initials end with period
* Colon after author name(s)
* Year at end (not after names)
* Journal names abbreviated

---

### **4. FIGURES & TABLES**

 **Figures** :

* Submit within body of text (unless file size issues)
* Resolution: 300 dpi minimum
* Formats: EPS (vector), TIFF (halftones)
* Width: 84mm (double-column) or 174mm (single-column)
* Maximum height: 234mm
* Number consecutively with Arabic numerals
* Cite in text in consecutive order

 **Tables** :

* Arabic numerals
* Provide caption/title
* Footnotes use superscript lowercase letters
* Cite in consecutive numerical order

---

### **5. REQUIRED DECLARATIONS** (on Title Page)

Include a **"Declarations"** section with:

| Declaration                    | Required?     | Example Wording                                                                                                                              |
| ------------------------------ | ------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| **Funding**              | Yes           | "The authors did not receive support from any organization for the submitted work." OR "This work was supported by [funder] grant [number]." |
| **Competing Interests**  | Yes           | "The authors have no relevant financial or non-financial interests to disclose."                                                             |
| **Ethics Approval**      | If applicable | "This study does not involve human participants or animals."                                                                                 |
| **Data Availability**    | Yes           | "The datasets generated during the current study are available in the [repository name] repository, [URL/DOI]."                              |
| **Code Availability**    | If applicable | "The code used in this study is available at [repository URL]."                                                                              |
| **Author Contributions** | Yes           | "Colin Priest: Conceptualization, Methodology, Data Analysis, Writing - Original Draft..."                                                   |

---

### **6. LLM/AI USE DISCLOSURE**

* LLMs **cannot be listed as authors**
* If LLMs used in research/writing: **Must document in Methods section**
* Exception: "AI-assisted copy editing" (grammar, spelling, style) does not need declaration
* Authors take **full responsibility** for all content

3. Upload anonymized manuscript
4. Upload title page separately

6. Upload supplementary materials (if any)
7. Submit
