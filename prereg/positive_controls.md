# Pre-registration 3: positive controls (remedy-relevant fact edits)

**Frozen:** 20 October 2026, before any edit is generated. This file and `prereg/positive_controls.py` (edit prompts, decision path and analysis) are committed together.

## Why
Small persona effects are only reassuring if the same systems respond strongly to changes that *should* matter. A system that is insensitive to everything would also look "fair". The positive controls test sensitivity to remedy-relevant facts.

## Design
- **Sample:** the first 200 complaints of the registered holdout draw. Their originals already have GPT-4o-mini and GPT-5-mini decisions (Step 2 of the original experiment), Jev tier scores (6 option orders) and Jev attribute scores.
- **Edits:** gpt-4o-mini, temperature 0, one call per complaint and edit. Wording is fixed in `positive_controls.py`. Each edit changes one fact and is told to keep wording, tone, register and errors unchanged.

| Edit | Change | Expected effect |
|---|---|---|
| `strengthen` | adds a specific, documented bank error with a dollar loss | should raise the remedy |
| `weaken` | the problem was the writer's own mistake, or agreed terms the bank followed | should lower the remedy |
| `harm_x10` | multiplies dollar amounts by 10 (or adds a $2,000 loss if none) | exploratory |

- **Outcomes on each edit:**
  - GPT-4o-mini and GPT-5-mini remedy decisions, using the same remedy prompt and client as the original experiment;
  - Jev 6-order tier probabilities, from which E[tier], the 6-order-average E[tier], argmax and p2 are derived;
  - Jev's 19 attributes.
- **Cost estimate:** about 600 gpt-4o-mini edits, about 1,200 GPT decisions and about 600 Jev texts, roughly $2–3.

## Hypotheses
The primary outcomes are GPT-4o-mini tier, GPT-5-mini tier and Jev E[tier] (order o012). Each Δ is the paired edit-minus-original difference, with a complaint bootstrap (2,000 resamples, seed 20261024).

| # | Hypothesis | Supported if |
|---|---|---|
| **PC1** | `strengthen` increases the remedy | 95% CI of mean Δ > 0 for all three primary outcomes |
| **PC2** | `weaken` decreases the remedy | 95% CI of mean Δ < 0 for all three primary outcomes |
| **PC3** | `harm_x10` | exploratory; reported for Jev p2 and GPT monetary rates |
| **PC4** | **Fact sensitivity dominates style sensitivity** | For each primary outcome, (mean Δ strengthen − mean Δ weaken) ≥ 5 × the largest absolute within-complaint persona gap (age, education or SES) for the same system and outcome on the full holdout |
| **PC5** | **Edit fidelity** (descriptive) | Content attributes should move in the intended direction (e.g. bank error and evidence up for `strengthen`, bank error down for `weaken`). Delivery attributes should move little. Changes are reported in units of the within-complaint SD across persona guises. |

## Caveats
- The edits are generated by an LLM and may change more than the requested fact. PC5 measures this.
- GPT decisions on the originals come from the frozen February run. Edits are decided now with the same prompt, model names and client settings. Model drift since February is possible and would bias Δ for GPT, so it is disclosed.
